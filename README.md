Projects developed in Java using Eclipse IDE.

Project 1 implements and evaluates linked lists and hash tables for managing two-dimensional data (x,y) in both main memory and disk storage, measuring comparisons and disk accesses.

Project 2 implements Binary Search Trees (BST) using arrays and dynamic memory allocation to perform insertions, searches, and deletions of keys while measuring execution times and comparison counts.

Project 3 implements Priority Queues (Heaps) using arrays and dynamic memory allocation with multiple construction methods, measuring construction times and average comparison counts per deletion.
